MATHSIDE V23.6 — STORAGE-SAVER STUDENT PHOTO UPDATE

1. Student written-solution photos now target about 450 KB per image before upload.
   - Maximum long edge starts at 1600 px.
   - Mathside lowers WebP quality gradually before reducing image dimensions.
   - A 900 px long-edge readability floor is used for unusually detailed images.

2. Student performance-task output photos use the same ~450 KB target.

3. Teacher assignment/rubric images keep their existing higher-quality compression settings.

4. HEIC/HEIF photos are still converted locally in the student's browser first, then compressed.
   Only the final compressed file is uploaded to Supabase Storage; the original HEIC/JPEG is not uploaded.

5. Existing V23.5 simple student passwords + HEIC fix, V23.4 submission filters/query optimizations, and V23.3 iOS Math Keyboard fixes are preserved.

NO SQL CHANGE IS REQUIRED.
NO EDGE FUNCTION CHANGE IS REQUIRED FOR V23.6.
